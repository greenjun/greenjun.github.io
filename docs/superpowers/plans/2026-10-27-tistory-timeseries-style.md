## 시계열 연재 목차

1. 백색소음: 확률과정과 관측값, 무상관과 독립
2. 정상성: 강정상성·약정상성과 랜덤워크
3. 자기상관: 자기공분산·ACF·PACF
4. 이동평균 모형 MA: 오차의 기억과 가역성
5. 자기회귀 모형 AR: 과거 값과 정상성
6. ARMA: ACF·PACF와 모형 비교
7. 변환·추세·차분: 정상화와 과차분
8. ARIMA: 적분 차수와 예측
9. 계절성·분해: 계절 패턴과 STL
10. SARIMA: 계절 차분과 계절 모형
11. 잔차 진단·예측구간: Ljung–Box와 불확실성
12. 예측 프로젝트: rolling-origin 검증과 최종 테스트

모든 편은 작성 완료 상태의 공개 목차에서 연결한다. 원본 3편의 다음 글 예고도 실제 작성된 후속편으로 연결한다.

## 정확성 검토 초점

- 백색소음의 무상관과 독립을 구분하고 유한 분산 조건을 적는다. 중심화가 공분산을 자동으로 0으로 만들지 않음을 바로잡는다.
- 정상성은 모든 예측의 필수조건이 아님을 설명하고 강정상성의 모든 유한 차원 결합분포 및 약정상성의 유한 이차 모멘트를 명시한다.
- ACF 대칭성·상한의 근거, 상관 제곱과 R²의 성립 범위를 설명한다.
- MA 가역성과 AR 정상성을 구분하고, 식의 부호와 R의 계수 관례를 맞춘다.
- 시계열 분해·변환·모형 선택은 평가 자료의 미래 정보를 사용하지 않는다. 예측구간과 평균 신뢰구간을 구분한다.

- 전체 포스트 31편: 기존 18편, 원문 이관 4편, 신규 시계열 9편. 소개 페이지의 CV 링크도 통합했다.
- 기존 18편에 글별 질문 도입·원리와 수식 풀이·질문형 소제목·다음 학습 결론을 적용했다. Git 기준 커밋과 대조하여 코드·제목·URL·날짜 메타데이터 보존을 확인했다.
- 향후 작성 기준은 원래 제공된 지침 내용을 보존한 루트 `AGENTS.md`와 README에 연결했다. 지침 파일은 사이트 출력에서 제외했다.
- 시계열 목차 12개 항목이 모두 완성된 포스트로 연결된다. 자료조사 원문의 자료원 12개를 모두 포함했다. 이관 원본·대상·원래 날짜는 `_data/tistory-migration.yml`로 추적한다.
- R 4.6.0, ggplot2 4.0.3, dplyr 1.2.1에서 26편의 코드 블록 88개를 순서대로 실행했다. 모든 코드가 오류 없이 완료되었고, 본문 코드와 검증한 코드의 일치도 확인했다.

- 로컬 Jekyll 빌드와 검색 테스트 5개 통과. 43개 HTML 페이지의 링크·이미지·앵커 1,814개 통과.
