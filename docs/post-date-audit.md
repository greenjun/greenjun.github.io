# 전체 게시글 날짜 점검 기록

점검일: 2026-10-27. 대상은 공개 게시글 31편이다. 게시물의 작성일·수정일과 연재 순서를 확인했다.

## 결과

- 2018년 6편, 2019년 12편, 2020년 13편으로 정리되어 있다. 게시물 작성일·수정일에 2022년·2026년은 남아 있지 않다.
- 시계열 1~12편은 2020-03-02부터 2020-05-18까지 매주 월요일 작성, 이틀 뒤 수요일 수정 일정이다.
- 산업 동향 자료조사 글은 다음 주인 2020-05-25 작성, 2020-05-27 수정으로 이어진다.
- 기존 날짜를 추가로 이동할 필요는 없었다. 파일명에서 작성일을 가져오던 2018년 6편에는 기존과 같은 날짜·자정·한국 시간대를 명시했다.
- 공개 주소와 기존 게시물 날짜는 유지한다. 이관 기록의 `source_published_at`·`source_modified_at`은 원본 자료의 실제 날짜이므로 보존한다.
- 푸터의 저작권 연도와 RSS 피드 자체의 생성 시각은 게시물의 작성일·수정일이 아니다. 해당 값은 별도로 구분한다.
