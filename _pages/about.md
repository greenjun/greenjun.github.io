## GreenJun에 오신 것을 환영합니다

이곳은 Junhyeok Yun이 통계와 데이터 분석을 공부하며 배운 내용을 정리하는 블로그입니다. 개념의 뜻을 이해하고, 예제를 통해 직접 적용하는 것을 목표로 합니다.

## 이런 내용을 다룹니다

| 주제 | 읽을 수 있는 내용 |
| --- | --- |
| 데이터 탐색 | 데이터의 구조, 분포, 결측값을 확인하는 EDA |
| 데이터 시각화 | R과 ggplot2로 만드는 막대그래프와 바이올린 플롯 |
| 데이터 축소 | 표본 추출, 집계, 주성분 분석(PCA)의 기본 개념 |
| 모델과 통계 해석 | 분류 모델의 평가 지표와 p-value의 올바른 해석 |

처음 시작한다면 [탐색적 데이터 분석(EDA)]({% post_url 2018-09-19-EDA %})부터 읽어보세요. 원하는 주제는 [주제별 글]({{ '/categories/' | relative_url }})이나 [태그]({{ '/tags-archive/' | relative_url }})에서도 찾을 수 있습니다.

## 글을 읽을 때 참고해 주세요

작성일은 글 목록에, 마지막 수정일은 각 글 하단에 표시됩니다. 코드 예제는 학습을 위한 것으로, 설치한 R과 패키지 버전에 따라 실행 결과나 그래프 모양이 달라질 수 있습니다.

통계적 결론은 데이터와 분석 가정에 따라 달라집니다. 글에 소개된 지표 하나만으로 판단하기보다, 목적과 데이터의 특성을 함께 살펴보세요.
